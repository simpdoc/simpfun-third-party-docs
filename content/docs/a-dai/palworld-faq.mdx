2.什么是启动时显示的绝对路径和相对路径？

此处先需要区分绝对路径和相对路径

Linux中由于没有可见的盘符，绝对路径就是您所看到的完整文件路径。例如：

`/home/container/start.sh`

```bash
/home/container/start.sh
```

相对路径指的是相对某一参照物的路径，在该镜像中为相对于启动脚本start.sh的路径，例如同级目录下的7zip文件夹：

```bash
/home/container/7zip
```

```bash
./7zip
```

3.我应当如何更新第三方幻兽帕鲁镜像版本？

1)等待镜像作者更新，容易存在存档丢失问题或者忘记下载备份文件的问题，因此推荐您手动更新服务端版本。

2)手动更新。您可参考《简幻欢幻兽帕鲁服务器手动更新教程》或者第三方平台的更新教程进行更新。

请借助解压功能和SFTP软件进行导入。导入后放入根目录下解压

6.镜像中的7zzs有其他用法吗？

```bash
chmod 777 ./7zzs         #处理权限问题
7zzs a xxx.7z a b c       #将a b c文件/文件夹压缩为xxx.7z，也可以是xxx.zip
7zzs e xxx.7z 解压绝对路径  #将xxx.7z解压至指定路径，也可以是xxx.zip
```

7.关机后我的帕鲁存档怎么回档了？怎么解决呢？

幻兽帕鲁服务端不支持在终端直接关机。您应当借助RCON工具来执行服务端命令或关机等操作。此处推荐[https://github.com/zkhssb/NectarRCON](https://github.com/zkhssb/NectarRCON)该项目软件，开源软件相对应的风险更小，不容易出现安全风险。

此处仅列出两个必要的指令：

DoExit 关机，会自动保存数据。

Save 保存服务端数据但不关机。

为防止回档，您应当通过DoExit来关机。RCON执行成功的截图如下：

![](/assets/docs/a-dai/image-MbtT.webp)

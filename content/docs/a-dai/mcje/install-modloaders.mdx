## Forge服务端

进入官网[https://files.minecraftforge.net/net/minecraftforge/forge/](https://files.minecraftforge.net/net/minecraftforge/forge/)，在左侧选择所需要的MC版本，然后点击Show all Versions打开版本菜单：![](/assets/docs/a-dai/mcje/ed7be752-0230-40d0-92f0-95f00dc39f65.webp)

这里我们以1.20.1的47.4.0版本为例，演示下载方法，点击Installer后方的该按钮跳过广告直接下载：

![](/assets/docs/a-dai/mcje/e70a38f9-f986-4045-9c2b-43c251b018fd.webp)

下载后我们会获得一个xxx.jar文件，双击打开。为了安装服务端，我们应当选择Install server选项，并在右下角 **···** 处选择合适的空白文件夹：

![](/assets/docs/a-dai/mcje/2062855a-66c4-4696-adb3-0b37a875592b.webp)

当出现以下内容时，说明服务端已经下载完毕：

![](/assets/docs/a-dai/mcje/544ebfa4-9cf8-4b77-8c3c-136895326b24.webp)

至此完成Forge服务端安装！

## Fabric服务端

进入官网[https://fabricmc.net/use/installer/](https://fabricmc.net/use/installer/)，点击青金石色的按钮Download for Winsdows，下载Fabric安装器后双击打开，先选中服务端，再选择MC版本、加载器版本和安装位置：

![](/assets/docs/a-dai/mcje/8456f565-11a0-408c-b929-7bb3d2d03713.webp)

然后点击安装，安装后还需要下载原版资源：

![](/assets/docs/a-dai/mcje/f9a4fd58-0f12-4d81-a25e-649d769f4474.webp)

在看到该提示后点击安装完成：

![](/assets/docs/a-dai/mcje/ccf889a4-5954-4341-a4f6-ea8c264f1506.webp)

至此完成Fabric服务端安装！

## NeoForge服务端

进入官网[https://neoforged.net/](https://neoforged.net/)，按照红字下载安装器：![](/assets/docs/a-dai/mcje/512127fc-4637-4a18-9f48-6d1b38d1229f.webp)

按照Forge教程，修改好红框配置项：

![](/assets/docs/a-dai/mcje/b019e631-4ede-4cae-8ce8-abcc02b4ba6a.webp)

笔者实测NeoForge安装器很容易出问题，建议通过PCL2下载安装器！

## 基础术语的介绍

### 环境变量

_设置环境变量，能让设备更好的运行进程，简化操作流程_

#### 这里以jdk17为例，设置JAVA\_HOME变量、Path变量

1.  右键桌面上的计算机图标，名称为"此电脑"/"我的电脑"
    
2.  此时会有一个"属性"选项，点击打开
    
3.  寻找"高级系统设置"，点击打开
    
4.  点击"环境变量"。此时不要动上方的用户变量，我们只操作系统变量
    
5.  找到系统变量中的Path，单击选中，点击编辑打开操作页面
    
6.  把%JAVA\_HOME%bin;填入
    
7.  新建一个系统变量JAVA\_HOME，路径选择你安装的jdk17的目录
    

至此便完成了环境变量的配置。

当您需要在powershell中(通常是开发环境)临时指定java版本时，可以这样做：

`$env:JAVA_HOME = "路径"`

`$env:Path = "$env:JAVA_HOME\bin;" + $env:Path`

`主命令`

### 客户端/服务端

客户端：客户端是完成实体和材质渲染和光线计算等的程序

服务端：服务端是负责管理多人游戏中的玩家交互、逻辑运算、数据同步和游戏世界维护的程序，既可以是独立服务器，也可以是内穿的主机端

### 模组加载器

_模组加载器指的是：在客户端和/或服务端加载模组的工具_

#### 常见的模组加载器如下所示：

Forge：一个老牌的模组加载器，优点是在老版本稳定，缺点是高版本性能不佳

Fabric：一个轻量的模组加载器，稳定性依赖于模组作者，**别忘了安装Fabric-api**

NeoForge：孵化于Forge的~狐狸~加载器，据说未来会有很大的性能更新

LiteLoader：老版本的模组加载器，1.13+退出了历史舞台

**部分模组需要同时在服务端和客户端添加，NeoForge端无法进入原版服务端**

### 光影加载器

_光影加载器指的是：在客户端加载光影，从而模拟自然光线的折射、散射等现象，使游戏中的场景、材质（如水体、树叶）呈现更细腻的视觉效果的工具_

#### 常见的光影加载器如下所示：

OptiFine：高清修复，老牌光影加载器； **~高版本的低清破坏~** **(****不要再往服务端扔高清修复了！！！！！！****)**

Iris Shader：Iris光影加载器，工作于Quilt(实在太少见了)/Fabric/NeoForge

Oculus：主要支持高版本Forge的光影加载器，兼容性良好

OptiFabric：Fabric端使用的高清修复

### 报错

_报错指的是：程序运行过程中由于软硬件错误产生的异常输出，是我的世界开服和游玩遇到困难最直接也最详细的信息获取途径_

#### 服务端常见报错

-   看门狗(Watchdog)报错，我的世界服务端的主线程挂起检测机制，通常由于生电漏斗过多、实体过多、模组加载顺序和加载内容异常、数据库挂起，区块卡死等引起，应当优先排查是否是掉落物过多引起（解决方案`kill @e[type=item`\]）
    
-   客户端类报错，将本该加载于客户端的模组加载于服务端造成的报错。典型报错为 `Attempted to load class net/minecraft/client/MouseHandler for invalid dist DEDICATED_SERVER` 、`Attempted to load class net/minecraft/client/gui/screens/Screen for invalid dist DEDICATED_SERVER` 等

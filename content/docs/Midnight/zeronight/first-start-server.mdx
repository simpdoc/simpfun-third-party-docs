## 服主操作流程

1.  新建实例，选择“第三方镜像”——"Minecraft 互通"，找到"ZeroNight 零夜·互通整合"，选择最新版开服即可。
    

2.  启动服务器后，Java版使用 `play.simpfun.cn:端口` 进入，基岩版则需要在服务器地址中填入 `play.simpfun.cn` ，端口处填写实例分配到的端口，如下所示：
    

![](/assets/docs/Midnight/zeronight/image-BtIS.webp)

![pVDpt6f-vccS.webp](/assets/docs/Midnight/zeronight/pVDpt6f-vccS.webp)

3.  首次进入服务器需要注册，打开聊天框输入`/reg 密码 确认密码` 后回车即可注册。例如`` /reg 147258369 147258369` ``
    
4.  后续进入服务器时需要输入 `/l 密码` 来进行登录操作。
    
5.  在控制台中输入 `op 你的id` 后回车来获取服务器内的管理权限。
    

## 玩家流程

参照服主流程的第二步到第四步。

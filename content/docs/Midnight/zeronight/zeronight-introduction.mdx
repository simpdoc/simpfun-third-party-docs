## 简介

整合包使用 Geyser 作为 JE-BE 互通的基础。

支持 Java 版 1.21.7——26.3，基岩版 26.50——26.6x 的原版增强向整合包。

该整合包满足基本游玩与管理，适合朋友联机/团建/养老。

Geyser 配置与 Floodgate 配置已进行设置，非必要不要乱动！

本整合包不含商店，经济，领地等功能，如有需要请移步 Midori‘s Dream 整合包（无Geyser）。

如果不需要JE-BE互通请移步 Momoi's Dream 整合包（无Geyser）。

## 如何安装

下面的方法三选一即可：

1.  前往[**简幻欢**](https://simpfun.cn/)——进入`控制台`——`新建实例`——右上角`切换到第三方镜像`——`Minecraft互通`，搜索`ZeroNight`即可。
    
2.  前往夸克网盘下载（推荐）：
    
    [https://pan.quark.cn/s/8df060466284](https://pan.quark.cn/s/8df060466284)
3.  前往百度网盘下载：
    
    [https://pan.baidu.com/s/12boKjbOeG19s3RoHiXzFvw?pwd=zero](https://pan.baidu.com/s/12boKjbOeG19s3RoHiXzFvw?pwd=zero)

## 我可以在服务端添加mod吗？

**不能！**这是插件服务端不是模组服务端！

但是你可以在客户端添加一些辅助mod，例如JEI，Jade，Carpet等。

## 客户端在哪下？

打开你常用的启动器，找到下载页面，选择一个服务端支持进入的客户端版本即可！

## 为什么不支持Java版1.7——1.19？

> **警告**
> 
> 请尽量使用与服务端相同版本的客户端进入游戏！

1.  此整合包没有安装ViaRewind（不支持1.7-1.9）；
    
2.  1.17及以下的版本进入1.18+的服务器会出现一些bug，包括但不限于：
    

-   1.16.5 及以下的客户端不支持 1.17+ 的新世界高度，客户端无法显示和交互 0 层以下的方块和 255 层以上的方块。
    

-   1.16.5 及以下的客户端在 1.17+ 服务器有时物品栏会不同步（幽灵物品）。
    

3.  新版本的物品特性无法在旧版本游戏内使用是因为ViaVersion**致力于兼容性而不是添加新的特性**。
    

因此我在viaversion的配置文件里锁死了最低版本为1.20，如果你确实有使用低版本的需求，请自行去配置文件删除相关配置。

## 如何修改一个IP最大玩家注册数量？

**方法1：**

使用简幻欢文件管理的配置项修改：

![](/assets/docs/Midnight/momoi-dream/image-pUUZ.webp)

**方法2：**

打开`/plugins/AuthMe/config.yml`，找到第200行的`maxRegPerIp`，保存后重载插件。

```yaml
# 每个IP地址允许的最大注册次数
# 值0表示注册次数不限！
maxRegPerIp: 2
```

## 不想要登录插件了可以删了吗？

## 没有画廊演示的侧边计分板？

由于简幻欢的流量机制问题，侧边计分板现在默认关闭，如果需要可以自行打开。

打开文件管理页面，找到`/plugins/TAB/config.yml`文件，找到如下所示的这部分内容，将 enabled 后的`false`改为`true`：

```yaml
scoreboard:
  enabled: false
  toggle-command: /sb
  remember-toggle-choice: false
  hidden-by-default: false
  use-numbers: false
  static-number: 0
  delay-on-join-milliseconds: 0
  scoreboards:
    scoreboard1:
      title: '%animation:ServerName%'
      lines:
      - '&6我的信息：'
      - '&b玩家id：&f%player_name%'
      - '&b当前称号：&r%playerTitle_use%'
      - '&b当前延迟：&6%player_ping% &bms'
      - '&b客户端版本：&5%viaversion_player_protocol_version%'
      - ''
      - '&6服务器信息：'
      - '&b在线玩家数：&a%online%&7/&c%server_max_players%'
      - '&bTPS：&r%server_tps_1_colored% %server_tps_5_colored%'
      - ''
      - '%animation:Tips%'
      - '&b%time%   %date%'
```

## 我用不了假人？

> **提示**
> 
> Leaves假人文档：[假人 | LeavesMC 文档](https://docs.leavesmc.org/zh_Hans/leaves/reference/fakeplayer)
> 
> 第三方镜像文档的镜像：[Leaves 假人文档](/docs/Midnight/Other-Docs/leaves-bot)

假人默认只允许有管理员权限的玩家使用。

将假人使用权限开放给玩家： `/lp group default permission set bukkit.command.bot true`

### 游戏内输入/bot后显示红色？

这是leaves的bug，如果你有权限不用管他。

## 启用刷线机

1.21.4+版本的Leaves服务端还原1.21.2之前的刷线机

在leaves.yml内找到这一行：

```yaml
string-tripwire-hook-duplicate: false
```

把 `false` 改成 `true` 后重启服务器。
